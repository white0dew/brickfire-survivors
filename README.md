# 钢铁余烬 // STEEL EMBERS

2026 年质感的高清像素坦克生存游戏：把 FC《坦克大战》的砖墙、钢墙、可破坏地形，和《吸血鬼幸存者》的自动开火、余烬升级、武器构筑、怪潮与 BOSS 战揉进一局 6 分钟的生存战。12 个连续星区、20 台可解锁坦克、16 种武器、22 种被动与 16 条进化路线，共 38 种升级协议。

纯静态网页，无构建步骤、无第三方运行时依赖。主菜单采用横向指挥栏：左/右键切换机库、单人/双人模式、出击、合成、图鉴、存档、帮助、设置；按「出击」进入战役星图并默认选中当前可挑战的最后一关，确认后再部署；白色选择块跟随键盘 / 手柄焦点移动。战役星区、机库坦克与战术道具都改为横向浏览条，减少重复说明，保留更大的可读字号。

## 运行

```bash
cd brickfire-survivors
python3 -m http.server 4173
```

打开 <http://127.0.0.1:4173/>。

直接双击 `index.html` 也能进入菜单，但建议用本地 HTTP 服务，避免部分浏览器对本地字体和音频的限制。首次点击「点火出击」后才会启动 WebAudio。

## 操作

| 输入 | 行为 |
| --- | --- |
| P1 键盘 | `WASD` 移动；`SPACE` 冲刺；`B` 回程 |
| P2 方向键 / 手柄左摇杆 | 移动 |
| 自动火控 | 正面半圆优先；正面没有目标时才转向背面，按距离选择 |
| `SPACE` / P2 `ENTER` / 手柄 `A` | 点火冲刺，短暂无敌 |
| `B` / 手柄 `Y` / 战斗区回程按钮 | 全队回程至基地，30 秒冷却 |
| `ESC` / 手柄 `START` | 暂停 / 继续 |
| `M` | 静音 |
| `F` | 全屏 |

单人时也可用方向键移动、手柄左摇杆移动。Xbox 手柄支持 `A` 冲刺、`START` 暂停与震动；双人时按连接顺序固定分配：第一只连接的手柄是 P1，第二只是 P2；设置里可手动「交换 P1/P2」，不会因为浏览器把手柄数组重新排序而抢占。主页和所有覆盖层支持十字键 / 左摇杆导航，`A` 确认，`B` 返回；主菜单默认聚焦「出击」，进入战役星图后默认选中当前可挑战的最后一关，机库覆盖层默认聚焦当前坦克，焦点到边界不回绕，长图鉴/说明用 `LB` / `RB` 翻页，焦点会自动滚入可见区域。手柄连接时底部显示当前界面的按键提示，页面固定为当前屏幕大小，不产生整页上下滚动。

触屏设备：左侧虚拟摇杆移动，自动索敌与自动开火；右下 `DASH` 冲刺，`HOME` 回程。横屏体验最佳；手机双人同屏建议外接手柄。

## 双人同屏

- 在主菜单点击「单人模式 / 双人模式」即可切换，当前模式直接显示在导航栏上。P1 键鼠，P2 可使用方向键或手柄；同时连接两只手柄时，第一只归 P1、第二只归 P2。
- 出击前 P1、P2 分别选择自己的底盘，各自获得该机型的装甲、速度、伤害、射速、暴击与专属特效；开局武器/被动按各自底盘独立配置。
- 等级、余烬、武器与被动按驾驶员独立；两辆坦克的装甲、冲刺冷却和开火节奏也独立。战斗 HUD 不再占用右侧栏：P1 信息在左上、P2 在右上，中央显示基地装甲，底部只保留武器/被动装载条与推进、回程操作；战场画面按可用高度放到最大。拾取道具的提示显示在对应驾驶员的角落 HUD 下方。
- 一人装甲归零会进入倒地状态，队友靠近 58px 并停留 2.4 秒可重启，恢复 35% 装甲。
- 两人都倒地才失败；活到 `06:00` 仍为共同胜利。
- 相机不拆分，两人始终在同一张 30×18 战场；敌人优先锁定存活车体，基地明显更近时才抢锁；哨戒壁垒会主动吸引火力。

## 战役流程

- 战役共 12 个星区，初始只开放第 1 关；通关当前星区后才会自动解锁下一关。
- 已通关星区可以重复挑战，进度保存在浏览器本机。
- 按「出击」打开战役星图；每关独立选择普通 / 困难 / 噩梦，默认选中当前可挑战的最后一关，点击星区后按「确认出击」部署。无尽协议单独成行，解锁后可在同一界面切换。
- 难度会调整敌军装甲、伤害、移速、刷新频率和泰坦生命，并提高结算合金核心奖励；每关难度分别保存在本机。
- 每关有独立的敌人 HP、速度、刷怪频率与余烬倍率词条；深层战区（第 9–12 星区）的泰坦额外强化。

## 敌人图鉴与存档

- 菜单「敌人图鉴」记录遭遇过的普通单位、精英单位和 Boss；共 26 个条目，包含 5 种普通敌人、20 种精英（含 19 台坦克的封印守卫）和泰坦 Boss。
- 未遭遇条目显示为 `???`，遭遇即永久记录到 `localStorage` 的 `bf.codex`；图鉴内有像素预览、英文代号和单位说明。
- 菜单「存档管理」可导出完整 JSON，包含战役星图、底盘解锁、P1/P2 机型、合金核心、记录和敌人图鉴。
- 导入存档会覆盖本机对应数据并刷新机库；导入前请先下载备份。存档只在浏览器本机处理，不上传服务器。

## 道具说明与回程

- 菜单「帮助」中的「战术与道具」列出全部 9 种战场掉落物、数值与使用场景；包含主炮升级、手雷、头盔、时钟、维修、备用车体、基地维修包、哨戒无人机和基地强化包。
- 高阶地形协议：Lv.8 后可选「两栖履带」直接穿越水面；Lv.12 后可选「相位弹芯」，让玩家炮弹穿过钢板且不损伤钢板，可从钢墙后安全输出。
- 敌人从顶部、基地两侧以及地图左右边缘的 18 个出生板持续压入；左右突击队每几秒从边缘入场，迫使玩家离开基地正面。
- 回程是全队即时传送：回到基地核心附近并获得短暂无敌，冷却 30 秒。战斗中可点底部「回程 / RECALL」、按 `B`，或用手柄 `Y`。

## 坦克解锁

- 初始只配发「先锋 M-01」；其余 19 台坦克在坦克库中显示为锁定。
- 解锁方式：每台锁定底盘对应一座关卡封印核心；击破核心后会召唤「封印守卫」，击败守卫永久解锁该底盘。19 座核心分布在前 12 个星区（每关 1–2 座），全部 19 台都可通过封印挑战解锁；合金核心可兑换作为替代路线。
- 每台锁定坦克也可用「合金核心」兑换。核心按每局击毁数和成功撤离结算，结算页会显示本局获得数量。
- 解锁、核心余额与 P1/P2 当前机型保存在本机 `localStorage` 的 `bf.hangar` / `bf.tanks`。

## 一局怎么玩

- 活到 `06:00` 撤离。车体归零、双人两人倒地，或基地装甲归零都会失败。
- 第一关进入战场时会弹出「首次部署」教学，演示战斗掉落余烬、经验升级与三选一构筑；可点击「开始作战」立即关闭。第一次拾取或看到战地道具掉落时，还会弹出一次道具教学，列出全部 9 种补给。
- 敌方优先锁定车体：基地距离按 `1.75` 倍权重计算，目标锁定 `3.2` 秒；只有车体倒地/死亡或锁定结束后才重新评估。
- 基地基础装甲 `520`；第一关作为教学关强化为 `780`，并自带 `2` 架哨戒无人机。其他关卡拾取「哨戒无人机」后才会在基地左/上/右三面部署环绕无人机，自动攻击并拦截 `315px` 内的敌方弹幕，底部为盲区。脱战 `7` 秒后基地以 `6 HP/s` 自行修复。
- 基地或车体归零即失败；双人时两辆车都倒地才失败，基地仍单独判定。
- 基地周围的砖墙带有青色保护标记：玩家火力和基地炮塔不会破坏它们，只有敌军炮弹和爆炸能拆墙。基地炮塔会越过墙体支援，但敌军必须先撕开防线。
- 敌人会锁定车体或基地，但车体优先：只有基地明显更近时才会抢锁；哨戒壁垒的嘲讽仍会强制拉走附近火力。拆墙、远程和 Boss 火力都会威胁基地。
- 封印核心属于可攻击目标；每次打中核心都会弹出 2 名增援小兵，击破核心再弹出 4 名并唤醒封印守卫。攻击封印不是安全站桩，必须边打边清场。
- 单人每局一次「应急核心」：致命伤时自动修复 40% 装甲并短暂无敌；双人改为倒地/救援机制。
- 击杀敌人掉落青色余烬，拾取后升级；升级时从三张协议卡中选一张。
- 武器最多 6 格，被动最多 6 格；武器 8 级、被动 5 级封顶。
- 刷怪频率按波次逐步提高，并在每分钟内继续缓慢加压；单人后段额外小幅加压。
- 砖墙可被炮弹打穿，钢墙和海水不可通行；善用地形卡住追兵。
- `04:45` 泰坦猎杀型 BOSS 降临；活到 `06:00` 即胜利，击破泰坦会在短暂爆炸后立即结算，不再空等倒计时。
- 掉落物：主炮升级（主炮提升 1 阶）、手雷（清屏）、头盔（护盾）、时钟（冻结）、维修（修复车体）、备用车体（修复）、基地维修包（修复基地 24% 装甲，基地受损后会进入掉落池）、哨戒无人机（基地左/上/右三向环绕，最多 4 架，拦截敌方弹幕）、基地强化包（基地装甲上限 +15% 并修复同等数值）。完整作用、数值与基地道具说明见菜单「帮助」。
- 自动火控只按朝向和距离锁定目标，不再检查火线；主炮和大多数常规副武器共用同一套正面半圆优先规则。弹道仍会被砖墙/钢板拦截，想拆墙需要靠射界和弹道本身。
- 「燃迹喷流」现在是双轨火痕，降低了火焰间隔、提高了持续时间和单跳伤害；满级会形成高密度火海。

## 设置与显示

- 主菜单右侧新增「设置」；战斗中暂停菜单也提供「设置」，无需退出战场。
- 可切换全屏、调整攻击音效音量（SFX）与 BGM 音量，两者独立保存到本机；BGM 音量只影响背景音乐，不改变攻击与爆炸音效。
- 音量滑杆支持键盘 / 手柄方向键调整；设置面板支持 `A` 切换、`B` 返回。全屏按钮也会同步显示当前状态。
- 「手柄分配」固定按首次连接顺序识别 P1/P2，并提供「交换 P1/P2」按钮；重新插拔后仍按连接顺序重新分配。

## 关卡 BGM

- 12 个星区各有一首独立循环 BGM；进入关卡时先播放约 5 秒部署提示音，再渐入当前关卡 BGM（第一关在关闭首次部署教学后开始）。主界面使用原第三关曲目循环播放，静音按钮会同步静音。
- 音频文件位于 `assets/audio/bgm/`，统一裁剪为约 90 秒、96 kbps 的循环段落，避免整首长曲拖慢加载。
- 关卡与主菜单曲目来自 Pixabay Music，按 Pixabay Content License 使用；部署提示音为参考视频的 5.1 秒片段。来源、作者与对应关卡记录在 `assets/audio/bgm/CREDITS.md`。
- 没有网络或首次加载音频失败时，会自动回退到原有的程序化合成配乐。

## 内容

- 12 张 30×18 战场：熔炉工厂 / 霓虹沼泽 / 霜蚀边陲 / 赤潮港 / 余烬高架 / 轨道墓场 / 零号反应堆 / 终焉穹顶 / 天穹堡垒 / 深渊泵站 / 日冕裂谷 / 边境王座，各自独立配色、地形和词条。
- 难度曲线：6 分钟一局，Boss 在 `04:45` 降临；常规波次在 `0/55/110/165/225/285` 秒升级，敌人生命约每分钟 `+25%`、伤害约每分钟 `+6.5%`。第一关使用独立教学修正：敌军生命 `-12%`、伤害 `-28%`、刷怪间隔 `+25%`、经验 `+15%`、Boss 生命 `-40%`；基地装甲提升到 `780`、自带 `2` 座哨戒炮、基地承伤 `-45%`，侧翼突击延后到 `22` 秒。第二关起恢复正常压力。
- 无尽协议：通关第 `2` 关后解锁，在星图中选择「无尽协议」进入。每 `75` 秒循环一轮波次，第一只 Boss 在 `02:00` 降临，击破后 `01:30` 刷新下一只；敌人生命/伤害继续按时间成长，刷怪上限随分钟数提高，没有撤离时间，车体或基地归零才结束。结算记录生存时间、等级、击毁数和首领击破数，并计入最佳生存时间。

- 20 台坦克：从先锋、双联、堡垒到焚化、雷暴、母舰、幽灵、天基 M-20，分别改变火力、生存、机动、资源或状态效果。
- 16 种武器：撕裂者主炮、环绕蜂群、电弧线圈、燃迹喷流、裂变地雷、轨道光矛、碎星霰弹、棱镜激光、黄蜂导弹、霜环发生器、天基动能棒、引力奇点、电浆迫击炮、哨戒壁垒、电磁脉冲矩阵、磁轨重炮。环绕蜂群围绕坦克旋转，自动攻击并拦截敌方子弹。
- 22 种被动：引擎超频、复合装甲、自动装弹机、磁力回收、高爆装药、冷却核心、暴击协议、余烬解析、过载输出、相位护盾、纳米修复、反应装甲、穿甲校准、矢量推进、回收协议、处决协议、纳米爆裂弹头、霜爆弹头、持续增幅、基地守护、两栖履带、相位弹芯。
- 技能按科技侧分工：轨道光矛负责持续远程重炮；天基动能棒负责延迟重击与首领点杀；电磁脉冲矩阵负责近场反弹幕与瘫痪；环绕蜂群负责贴身索敌、拦截敌弹并形成移动屏障；哨戒壁垒负责嘲讽、承伤和守区；不再使用流星召唤类幻想技能。
- 16 条进化路线：每把武器都有一条独立融合；对应武器升到第 2 格（Lv.3）且被动升到第 2 格（Lv.2）后，升级卡会出现合成协议。菜单「合成表」可查看全部路线。
- 6 波常规潮汐 + 精英破城者 + 泰坦 BOSS；泰坦阶段仍持续刷怪，Boss 会使用重炮、扇形弹幕、震荡波和召唤编队。
- 程序化像素图标与大部分音效；12 首关卡 BGM、1 首主界面 BGM 和 1 段约 5 秒部署提示音使用本地音频文件，并提供程序化回退。
- 本地记录：最高生存、最高等级、成功撤离次数；战役解锁/通关与难度、P1/P2 机型、坦克解锁、合金核心、敌人图鉴持久化。

## 技术结构

| 文件 | 职责 |
| --- | --- |
| `index.html` | 机库、战斗 HUD、升级/暂停/结算/简报界面 |
| `css/style.css` | 视觉系统、切角面板、扫描线、响应式与移动端布局 |
| `js/content.js` | 12 张战场、敌人、16 种武器、22 种被动、20 台坦克、16 条合成、道具、波次与数值配置 |
| `js/icons.js` | 20×20 程序化像素图标 |
| `js/audio.js` | WebAudio 音效、关卡 BGM 播放与程序化回退 |
| `js/game.js` | 主循环、输入、战斗、AI、升级、HUD、渲染 |
| `js/main.js` | 启动入口与错误捕获 |

渲染使用 960×576 内部分辨率、32px 瓦片、Canvas 2D，CSS 以 `image-rendering: pixelated` 放大；战场按视口宽高比自适应，2K/4K 下会移除旧的 1500px 上限并放大 HUD 字号。敌方寻路使用 Dijkstra + 最小堆流场；砖墙可挖掘、钢墙/水域/撤离信标阻断。音效与回退音乐实时合成；12 首关卡 BGM、1 首主界面 BGM 与 1 段部署提示音为本地音频文件，进入关卡时先播放提示音再循环 BGM。

## 浏览器

建议使用近两年的 Chrome、Edge、Safari 或 Firefox。需要 Canvas 2D、WebAudio、CSS `clip-path` 与 `svh` 支持。移动端横屏布局会自动收起侧栏，保留战场、撤离进度/装甲条、摇杆与冲刺键。
