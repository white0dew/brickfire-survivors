# BRICKFIRE // 砖火幸存者

2026 年质感的高清像素坦克生存游戏：把 FC《坦克大战》的砖墙、钢墙、可破坏地形，和《吸血鬼幸存者》的自动开火、余烬升级、武器构筑、怪潮与 BOSS 战揉进一局 6 分钟的生存战。12 个连续星区、20 台可解锁坦克、6 条武器合成路线。

纯静态网页，无构建步骤、无第三方运行时依赖。

## 运行

```bash
cd brickfire-survivors
python3 -m http.server 4173
```

打开 <http://127.0.0.1:4173/>。

直接双击 `index.html` 也能进入菜单，但建议用本地 HTTP 服务，避免部分浏览器对本地字体和音频的限制。首次点击「点火出击」后才会启动 WebAudio。

## 操作

| 输入 | 行为 |
| --- | --- |
| P1 `WASD` | 移动 |
| P1 鼠标 | 瞄准；按住左键持续开火 |
| P2 方向键 / 手柄左摇杆 | 移动 |
| P2 手柄右摇杆 | 瞄准；`RT` / `LT` 强制开火 |
| 自动索敌 | 未手动瞄准时自动锁定最近目标 |
| `SPACE` / P2 `ENTER` / 手柄 `A` | 点火冲刺，短暂无敌 |
| `ESC` / 手柄 `START` | 暂停 / 继续 |
| `M` | 静音 |
| `F` | 全屏 |

单人时也可用方向键移动、手柄左/右摇杆移动/瞄准。Xbox 手柄支持 `A` 冲刺、`START` 暂停与震动。

触屏设备：左侧虚拟摇杆移动，自动索敌与自动开火；右下 `DASH` 冲刺；点按/拖动战场可手动瞄准并开火。横屏体验最佳；手机双人同屏建议外接手柄。

## 双人同屏

- 菜单选择「双人合作 / CO-OP」，P1 键鼠，P2 手柄；P2 也可用方向键移动、`ENTER` 冲刺。
- 出击前 P1、P2 分别选择自己的底盘，各自获得该机型的装甲、速度、伤害、射速、暴击与专属特效；开局武器/被动取两人起始配置的并集。
- 等级、余烬、武器与被动共享；两辆坦克的装甲、冲刺冷却和开火节奏独立。
- 一人装甲归零会进入倒地状态，队友靠近 58px 并停留 2.4 秒可重启，恢复 35% 装甲。
- 两人都倒地才失败；活到 `06:00` 仍为共同胜利。
- 相机不拆分，两人始终在同一张 30×18 战场；敌人追最近的存活车体或基地。

## 战役流程

- 战役共 12 个星区，初始只开放第 1 关；通关当前星区后才会自动解锁下一关。
- 已通关星区可以重复挑战，进度保存在浏览器本机。
- 菜单的「战役星图」打开关卡地图；每关独立选择普通 / 困难 / 噩梦，点击可挑战的星区后返回机库再出击。
- 难度会调整敌军装甲、伤害、移速、刷新频率和泰坦生命，并提高结算合金核心奖励；每关难度分别保存在本机。
- 每关有独立的敌人 HP、速度、刷怪频率与余烬倍率词条；深层战区（第 9–12 星区）的泰坦额外强化。

## 敌人图鉴与存档

- 菜单「敌人图鉴」记录遭遇过的普通单位、精英单位和 Boss；共 26 个条目，包含 5 种普通敌人、20 种精英（含 19 台坦克的封印守卫）和泰坦 Boss。
- 未遭遇条目显示为 `???`，遭遇即永久记录到 `localStorage` 的 `bf.codex`；图鉴内有像素预览、英文代号和单位说明。
- 菜单「存档管理」可导出完整 JSON，包含战役星图、底盘解锁、P1/P2 机型、合金核心、记录和敌人图鉴。
- 导入存档会覆盖本机对应数据并刷新机库；导入前请先下载备份。存档只在浏览器本机处理，不上传服务器。

## 坦克解锁

- 初始只配发「先锋 M-01」；其余 19 台坦克在坦克库中显示为锁定。
- 解锁方式：每台锁定底盘对应一座关卡封印核心；击破核心后会召唤「封印守卫」，击败守卫永久解锁该底盘。19 座核心分布在前 12 个星区（每关 1–2 座），全部 19 台都可通过封印挑战解锁；合金核心可兑换作为替代路线。
- 每台锁定坦克也可用「合金核心」兑换。核心按每局击毁数和成功撤离结算，结算页会显示本局获得数量。
- 解锁、核心余额与 P1/P2 当前机型保存在本机 `localStorage` 的 `bf.hangar` / `bf.tanks`。

## 一局怎么玩

- 活到 `06:00` 撤离。车体归零、双人两人倒地，或基地装甲归零都会失败。
- 基地有 `1000` 点装甲，会自动攻击 `315px` 内最近敌军，每发 `25` 伤害；脱战 `7` 秒后以 `6 HP/s` 自行修复。
- 基地或车体归零即失败；双人时两辆车都倒地才失败，基地仍单独判定。
- 基地周围的砖墙带有青色保护标记：玩家和基地火力不会破坏它们，只有敌军炮弹和爆炸能拆墙。基地火力会越过墙体支援，但敌军必须先撕开防线。
- 敌人优先锁定最近的存活车体或基地；拆墙、远程和 Boss 火力都会威胁基地。
- 单人每局一次「应急核心」：致命伤时自动修复 40% 装甲并短暂无敌；双人改为倒地/救援机制。
- 击杀敌人掉落青色余烬，拾取后升级；升级时从三张协议卡中选一张。
- 武器最多 6 格，被动最多 6 格；武器 8 级、被动 5 级封顶。
- 刷怪频率按波次逐步提高，并在每分钟内继续缓慢加压；单人后段额外小幅加压。
- 砖墙可被炮弹打穿，钢墙和海水不可通行；善用地形卡住追兵。
- `04:45` 泰坦猎杀型 BOSS 降临；活到 `06:00` 即胜利，击破泰坦会在短暂爆炸后立即结算，不再空等倒计时。
- 掉落物：星星（主炮升级）、手雷（清屏）、头盔（护盾）、时钟（冻结）、维修（修复车体）、备用车体（修复）、基地维修包（修复基地 24% 装甲，基地受损后由精英怪掉落）。
- 升级卡带有常规 / 稀有 / 史诗 / 传说四档稀有度；高稀有度选项更少见，稀有 / 史诗 / 传说会额外提升 1 / 2 / 3 个等级，且升级候选的稀有度会随局内等级变化。
- 自动开火会检查火线：若目标被砖墙或钢板挡住，自动炮会保持停火，避免主动拆掉自己的掩体；鼠标/触控手动瞄准仍可拆墙。
- 「燃迹喷流」现在是双轨火痕，降低了火焰间隔、提高了持续时间和单跳伤害；满级会形成高密度火海。

## 内容

- 12 张 30×18 战场：熔炉工厂 / 霓虹沼泽 / 霜蚀边陲 / 赤潮港 / 余烬高架 / 轨道墓场 / 零号反应堆 / 终焉穹顶 / 天穹堡垒 / 深渊泵站 / 日冕裂谷 / 边境王座，各自独立配色、地形和词条。
- 20 台坦克：从先锋、双联、堡垒到焚化、雷暴、母舰、幽灵、毒蝎，分别改变火力、生存、机动、资源或状态效果。
- 6 种武器：撕裂者主炮、蜂群无人机、电弧线圈、燃迹喷流、裂变地雷、轨道审判。
- 10 种被动：引擎、装甲、装填、磁力、战斗部、冷却、暴击、回收、过载、护盾。
- 6 条合成路线：主炮+过载、无人机+装填、电弧+冷却、喷流+战斗部、地雷+装甲、轨道+暴击；对应武器 Lv.6 且被动 Lv.2 后，升级卡会出现合成协议。
- 6 波常规潮汐 + 精英破城者 + 泰坦 BOSS；泰坦阶段仍持续刷怪，Boss 会使用重炮、扇形弹幕、震荡波和召唤编队。
- 程序化像素图标、程序化音效与 32 步循环配乐，不依赖外部音频/图片素材。
- 本地记录：最高生存、最高等级、成功撤离次数；战役解锁/通关与难度、P1/P2 机型、坦克解锁、合金核心、敌人图鉴持久化。

## 技术结构

| 文件 | 职责 |
| --- | --- |
| `index.html` | 机库、战斗 HUD、升级/暂停/结算/简报界面 |
| `css/style.css` | 视觉系统、切角面板、扫描线、响应式与移动端布局 |
| `js/content.js` | 12 张战场、敌人、武器、被动、20 台坦克、6 条合成、波次与数值配置 |
| `js/icons.js` | 20×20 程序化像素图标 |
| `js/audio.js` | WebAudio 合成音效与循环音乐 |
| `js/game.js` | 主循环、输入、战斗、AI、升级、HUD、渲染 |
| `js/main.js` | 启动入口与错误捕获 |

渲染使用 960×576 内部分辨率、32px 瓦片、Canvas 2D，CSS 以 `image-rendering: pixelated` 放大。敌方寻路使用 Dijkstra + 最小堆流场；砖墙可挖掘、钢墙/水域/撤离信标阻断。音效和音乐全部实时合成。

## 浏览器

建议使用近两年的 Chrome、Edge、Safari 或 Firefox。需要 Canvas 2D、WebAudio、CSS `clip-path` 与 `svh` 支持。移动端横屏布局会自动收起侧栏，保留战场、撤离进度/装甲条、摇杆与冲刺键。
